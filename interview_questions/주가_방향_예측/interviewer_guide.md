# 주가_방향_예측 - 면접관 가이드

## AI 엔지니어 면접 문제 (주가 방향 예측) 면접관 숙지 사항

### 핵심 기술 및 개념

면접관은 후보자가 다음 기술 및 개념에 대한 이해와 활용 능력을 갖추었는지 평가해야 합니다.

1.  **데이터 처리 (Pandas):**
    *   CSV 파일 로딩 (`pd.read_csv`)
    *   데이터프레임 병합 (`pd.merge`) - 특히 `date` 컬럼 기준 병합 능력 확인
    *   데이터프레임 인덱싱 및 슬라이싱 (특정 컬럼 선택, 조건 필터링 등)
    *   결측치 확인 및 기본적인 처리 (여기서는 마지막 행 제외 로직에 해당)
    *   `.shift()` 함수 활용 능력 (시계열 데이터에서 이전/다음 값 참조)

2.  **특징 공학 (Feature Engineering):**
    *   문제 정의에 따른 특징(Features) 선택 (`close`, `sentiment_score`) 능력
    *   문제 정의에 따른 타겟 변수(Label/Target) 생성 능력 - 특히 다음 거래일과의 비교 로직 (`shift(-1)` 활용) 및 이진 분류 (0/1) 변환
    *   시계열 데이터의 특성 이해 (현재 정보로 미래 예측, 마지막 데이터 처리)

3.  **머신러닝 모델링 (Scikit-learn):**
    *   지도 학습 (Supervised Learning) 기본 개념 이해 (특징-타겟 관계)
    *   분류 (Classification) 문제 정의 및 모델 선택 (Logistic Regression)
    *   Scikit-learn API 활용 능력:
        *   모델 인스턴스 생성 (`LogisticRegression()`)
        *   모델 학습 (`model.fit(X, y)`)
        *   예측 (`model.predict(X)`)
    *   모델 성능 평가: Accuracy(정확도) 개념 이해 및 계산 (`accuracy_score` 또는 `model.score(X, y)`)

### 주의사항

후보자의 접근 방식을 평가할 때 다음 사항에 유의해야 합니다.

1.  **타겟 변수 생성 로직의 정확성:**
    *   **핵심:** 당일 종가와 **다음 날** 종가를 비교하여 상승(1)/하락 또는 유지(0)를 정확히 라벨링하는지 확인합니다. `shift()` 함수의 인자(-1)를 올바르게 사용하는지 확인해야 합니다.
    *   마지막 날 데이터는 다음 날 종가가 없으므로 타겟 변수를 생성할 수 없어 제외해야 합니다. 이 부분을 명확히 처리하는지 확인합니다. (예: `dropna()` 사용)

2.  **특징(Feature) 선택의 적절성:**
    *   문제에서 명시된 대로 **당일**의 `close`와 `sentiment_score`만을 특징으로 사용하는지 확인합니다. 실수로 **다음 날**의 정보(예: `shift(-1)`된 종가)를 특징에 포함시키면 미래 정보를 예측에 사용하는 **데이터 누수(Data Leakage)**가 발생하므로 감점 요인입니다.

3.  **코드 구현 및 라이브러리 활용 능력:**
    *   Pandas와 Scikit-learn의 기본적인 함수를 정확하게 사용하는지 확인합니다.
    *   제한 시간(30분) 내에 요구사항을 완수하는 효율성도 고려합니다.
    *   코드가 논리적으로 명확하고 이해하기 쉬운지 간략하게 평가합니다. (주석 사용 등)
    *   명시된 모델(Logistic Regression)과 평가 지표(Accuracy)를 사용하는지 확인합니다.

### 질문 가이드

면접 중 다음과 같은 질문을 통해 후보자의 이해도를 심층적으로 파악할 수 있습니다.

1.  **타겟 변수 생성 관련:**
    *   "타겟 변수(다음 날 주가 방향)를 어떻게 생성하셨는지 설명해주시겠어요? `shift()` 함수를 사용한 이유가 무엇인가요?"
    *   "데이터의 마지막 날짜는 왜 모델 학습/평가에서 제외되어야 하나요?"

2.  **모델 및 평가 관련:**
    *   "이 문제를 해결하기 위해 Logistic Regression을 사용해야 하는 이유는 무엇이라고 생각하시나요? (또는 문제에서 왜 이 모델을 지정했을 것 같나요?)"
    *   "계산된 Accuracy 점수는 무엇을 의미하나요? 이 점수만으로 모델 성능을 판단하기에 충분할까요? (특히 금융 데이터에서)" (Accuracy의 한계점, 불균형 데이터 문제 등 유도)

3.  **개선 및 확장 관련:**
    *   "만약 모델 성능을 더 높여야 한다면 어떤 방법을 시도해볼 수 있을까요?" (다양한 특징 추가, 다른 모델 사용, 하이퍼파라미터 튜닝, Train/Test 분할 등)
    *   "주가 예측 문제에서 뉴스 감성 점수 외에 어떤 데이터가 더 도움이 될 수 있을까요?" (거래량, 기술적 지표, 거시 경제 지표 등)
    *   "실제 주식 투자에 이 모델을 바로 적용할 수 있을까요? 주의할 점은 무엇일까요?" (과적합, 시계열 특성 미반영, 현실과의 괴리 등)
