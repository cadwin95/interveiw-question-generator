### 문제 제목
LLM 뉴스 요약 환각 제어 설계

### 문제 설명
**상황:**
귀하는 최신 뉴스 기사를 요약하여 사용자에게 제공하는 서비스의 AI 엔지니어입니다. 서비스는 **이미 운영 중인 특정 사전 훈련된 LLM**을 핵심으로 사용합니다. 이 LLM은 성능이 좋지만, 때때로 원문에 없거나 사실과 다른 내용을 요약문에 포함하는 '환각(Hallucination)' 현상을 보입니다. 서비스 신뢰도를 위해, **기존 LLM을 직접 수정하거나 교체하지 않고** 환각 현상을 최소화하는 실용적인 시스템/파이프라인 설계가 필요합니다.

**요구사항:** (120분 내 완료)
1.  **환각 완화 전략 정의:** 사용할 기술(들) (예: RAG, 프롬프트 엔지니어링, 후처리, 보조 모델 활용 등)을 명시하고, 선택 이유, 작동 원리, 조합 시 역할 분담을 설명하십시오.
2.  **시스템 아키텍처 설계:** 사용자 요청부터 최종 요약문 생성까지 데이터 흐름과 구성 요소를 포함한 아키텍처를 설명하고, 환각 완화 전략이 어떻게 통합되는지 명시하십시오.
3.  **핵심 컴포넌트 상세 로직 설명:** 설계한 시스템의 핵심 컴포넌트 중 하나를 선택하여, 주요 동작 원리(알고리즘)를 단계별로 설명하십시오. (Pseudo-code/순서도 대신 논리적 흐름 기술)
4.  **성능 평가 방안:** 설계한 시스템의 효과 측정 전략, 핵심 지표(Metrics)와 선정 이유, 평가 시 예상되는 주요 어려움 및 접근 방식을 설명하십시오.
5.  **기술적 트레이드오프(Trade-offs):** 설계 도입 시 예상되는 장단점을 응답 속도, 비용, 시스템 복잡도/유지보수성 관점에서 분석하고, 이를 어떻게 절충/관리할지 설명하십시오.

### 평가 포인트
- 환각 현상 및 관련 완화 기술 이해도
- 주어진 제약 하에서의 실현 가능하고 논리적인 시스템 설계 능력
- 실용적이고 창의적인 문제 해결 접근 방식
- 기술 선택 근거 및 운영 관점(속도, 비용, 복잡도 등)의 트레이드오프 분석 능력
- 체계적이고 현실적인 성능 평가 전략 수립 및 평가의 어려움 인지 능력

### 제약 조건
- 기존 운영 중인 LLM의 핵심 가중치 직접 수정 또는 모델 교체 불가
- 실용적인 엔지니어링 및 운영 관점에서 접근
- 120분 시간 제한 내 요구사항 완료
