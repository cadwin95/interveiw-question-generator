### 문제 제목

실시간 이상탐지 긴급 대응

### 문제 설명

**상황:**

당신은 금융 거래 서비스 회사에 AI 엔지니어로 합류했습니다. 현재 시스템은 실시간으로 들어오는 사용자 거래 데이터를 분석하여 이상 거래(사기 의심)를 탐지하는 머신러닝 모델(예: Isolation Forest, Autoencoder 등)을 사용하고 있습니다. 최근, **이전에는 관측되지 않았던 새로운 유형의 사기 패턴**이 등장하여 기존 모델의 탐지율(Recall)이 눈에 띄게 하락했습니다. **이 새로운 패턴은 아직 명확하게 레이블링되지 않았을 가능성이 높습니다.** 탐지율 하락은 회사에 직접적인 금전적 손실을 야기할 수 있어 **매우 신속한 초기 대응**이 필요한 상황입니다.

**과제:**

주어진 30분 동안, 이 문제를 해결하기 위한 **현실적인 긴급 초기 대응 전략**을 구체적으로 설명하고, **예상되는 어려움**과 **대응 성공 여부를 판단할 기준**을 제시해주세요. 단순히 "더 좋은 모델을 학습시킨다" 이상의 구체적이고 실용적인 계획이 필요합니다.

**발표/설명 내용에 포함되어야 할 사항:**

1.  **문제 분석 및 가설 설정:** 탐지율 하락의 가장 가능성 높은 원인에 대한 가설을 1~2가지 제시하세요. (예: 데이터 분포 변화, 신규 패턴 미학습 등)
2.  **긴급 데이터 분석 계획:** 현재 상황을 빠르게 진단하고 가설을 검증하기 위해 어떤 데이터를 어떻게 분석할 것인지 설명하세요. (어떤 피처 확인? 어떤 시각화 활용? 어떤 통계 분석?)
3.  **단기적 대응 방안 (1~2가지):** 즉각적인 피해를 줄이거나 상황을 안정화하기 위해, 현재 운영 중인 모델이나 시스템에 **신속하게 적용 가능한** 실용적인 아이디어를 1~2가지 제시하고, 그 이유를 설명하세요. (반드시 새로운 모델 개발이 아니어도 됩니다. 예: Rule-based 시스템 임시 추가/강화, 특정 피처 가중치 조정, 탐지 임계값 조정, 최신 의심 거래 데이터의 제한적 활용 방안 등)
4.  **예상되는 기술적/운영적 어려움:** 제시한 단기 대응 방안을 실행할 때 발생할 수 있는 주요 어려움을 1~2가지 예측해보세요. (예: 신규 패턴 레이블 부재, 실시간 적용 및 테스트의 어려움, 기존 시스템과의 충돌 가능성 등)
5.  **성공 지표 및 균형점:** 제안한 대응 방안의 성공 여부를 어떻게 측정할 것인지 구체적인 지표(Metric)를 설명하세요. 단순히 Recall 개선 외에, **정상 거래에 미치는 영향(예: 오탐 증가로 인한 사용자 불편 및 운영 비용 증가)** 등 다른 비즈니스적 고려사항과의 균형점을 어떻게 판단할지도 포함하여 설명하세요.

**평가 기준:**

*   **문제 정의 및 분석 능력:** 현 상황의 긴급성을 이해하고 문제의 핵심 원인을 논리적으로 빠르게 추론하는가?
*   **실용적/긴급 대응 능력:** 제한된 시간과 정보 하에서 현실적으로 즉시 실행 가능한 초기 대응 방안을 제시하는가?
*   **기술적 이해도:** AI/ML 모델, 데이터 분석, 실시간 시스템 운영에 대한 기본적인 이해를 바탕으로 해결책을 제안하는가?
*   **비판적 사고:** 제안한 방법의 한계점이나 발생 가능한 문제를 예측하고 균형점을 고려하는가?
*   **명확한 커뮤니케이션:** 자신의 아이디어를 체계적이고 명확하게 설명하는가?

**(참고: 코딩을 직접 수행하는 과제는 아닙니다. 문제 해결을 위한 접근 방식과 사고 과정을 발표/설명하는 과제입니다.)**

## 데이터 생성

데이터 생성 코드는 `generate_data.py` 파일에 저장되어 있습니다.

### 실행 방법
다음 방법 중 하나를 선택하여 실행할 수 있습니다:

1. 자동 실행 스크립트 사용:
```bash
./run_data_generation_20250414_145615.sh
```

2. Python 스크립트 직접 실행:
```bash
python generate_data.py
```

### 로그 확인
실행 로그는 `logs/data_generation.log` 파일에서 확인할 수 있습니다.
