### 문제 제목
스팸 오탐지 분석

### 문제 설명
**상황:**
TF-IDF + Logistic Regression 기반 스팸 메일 분류 모델을 운영 중입니다. 전반적인 정확도는 높지만, 특정 유형의 정상 메일(주로 이벤트/할인 정보 뉴스레터)을 스팸으로 잘못 분류하는 오탐(False Positive) 비율이 다른 정상 메일에 비해 유독 높게 나타나고 있습니다. 문제 해결을 위해 원인 분석이 필요한 상황입니다. 제한적인 오탐지 메일 샘플 4건과 참고용 정상 메일 1건이 주어집니다. (모델은 기본 영문 불용어 처리, 어근 추출 미적용, 단어 빈도 기반 TF-IDF 사용)

**요구사항:**
1.  주어진 샘플 패턴을 기반으로 오탐지 발생의 가능성 있는 원인(가설)을 2가지 이상 제시하세요.
2.  각 가설을 검증하기 위해 필요한 추가 데이터 분석이나 실험 방법을 구체적으로 설명하세요.
3.  가설이 맞다고 가정했을 때, 시도해 볼 수 있는 해결 방안을 제시하세요.

### 평가 포인트
-   제한된 정보(모델 특성, 샘플 패턴) 내에서 논리적인 가설을 설정하는 능력
-   가설 검증을 위해 필요한 추가 데이터/분석/실험을 구체적으로 설계하는 능력
-   문제 해결을 위한 다양한 접근 방식(데이터, 피처, 모델 등) 제시 능력

### 제약 조건
-   제공된 샘플은 통계적 분석을 하기에 매우 부족함 (패턴 관찰 및 논리적 추론 집중)
-   모델 및 전처리 방식은 주어진 정보로 한정함
-   문제 해결 시간: 30분

### 문제 제목
캡셔닝 API 개선

### 문제 설명
**상황:**
외부 클라우드 AI 서비스의 사전 훈련된(Pre-trained) 범용 이미지 캡셔닝 API를 사용하여 서비스 내 이미지에 설명을 자동 추가하고 있습니다. 하지만 특정 유형의 이미지(예: 여러 객체가 복잡하게 얽힌 이미지, 추상적 패턴, 특정 문화권 요소 등)에 대해 부정확하거나 매우 일반적인 수준의 캡션만 생성되는 문제가 있습니다.

**요구사항:**
1.  API 자체를 수정하거나 재학습시키는 것은 불가능하다고 가정할 때, 캡션 품질을 개선하기 위해 시도할 수 있는 방법을 3가지 제시하세요.
2.  제시된 방법들은 별도의 대규모 모델 재학습 없이 기존 시스템에 비교적 용이하게 통합 가능해야 합니다.
3.  각 방법의 장단점을 간략하게 설명하세요.

### 평가 포인트
-   주어진 제약 조건 하에서 창의적이고 실현 가능한 해결책을 모색하는 능력
-   다양한 AI 관련 기술(Prompt Engineering, 후처리, 다른 모델/API 조합, 메타데이터 활용 등)에 대한 이해 및 응용력
-   각 방법의 기술적/운영적 장단점을 고려하는 균형 잡힌 시각

### 제약 조건
-   사용 중인 외부 API 자체의 수정 및 재학습 불가
-   별도의 대규모 모델 재학습 없이, 비교적 용이하게 통합 가능한 방법 모색
-   문제 해결 시간: 30분

## 데이터 생성

데이터 생성 코드는 `generate_data.py` 파일에 저장되어 있습니다.

### 실행 방법
다음 방법 중 하나를 선택하여 실행할 수 있습니다:

1. 자동 실행 스크립트 사용:
```bash
./run_data_generation_20250414_151100.sh
```

2. Python 스크립트 직접 실행:
```bash
python generate_data.py
```

### 로그 확인
실행 로그는 `logs/data_generation.log` 파일에서 확인할 수 있습니다.
