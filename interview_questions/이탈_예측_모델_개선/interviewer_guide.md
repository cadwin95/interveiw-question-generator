# 이탈_예측_모델_개선 - 면접관 가이드

## AI 엔지니어 면접 문제 (이탈 예측 모델 개선) - 면접관 숙지 사항

**목표:** 후보자가 데이터 불균형 문제의 본질을 이해하고, 적절한 평가지표를 활용하며, 실질적인 해결 방안과 그에 따른 트레이드오프를 고려하여 문제를 해결할 수 있는지 평가합니다.

### 핵심 기술 및 개념

면접관은 다음 개념에 대한 후보자의 이해도를 중점적으로 확인해야 합니다.

1.  **데이터 불균형 (Data Imbalance):**
    *   정의: 특정 클래스(여기서는 이탈 고객)의 데이터 샘플 수가 다른 클래스(유지 고객)에 비해 현저히 적은 상태.
    *   문제점: 모델이 다수 클래스(유지 고객)에 과적합(overfitting)되어 소수 클래스(이탈 고객)를 제대로 예측하지 못하게 만듦. Accuracy는 높게 나오지만, 실제 중요한 소수 클래스 예측 성능(Recall)은 낮은 현상 발생.
2.  **분류 모델 평가지표 (Classification Metrics):**
    *   **Accuracy (정확도):** 전체 예측 중 올바르게 예측한 비율. 데이터 불균형 시 모델 성능을 오도할 수 있음 (다수 클래스만 잘 맞춰도 높게 나옴).
    *   **Recall (재현율) / Sensitivity / True Positive Rate (TPR):** 실제 Positive(이탈) 중 모델이 Positive(이탈)로 예측한 비율. **FN(False Negative)을 줄이는 것이 중요할 때** (이탈 고객을 놓치면 안 될 때) 핵심 지표. (TP / (TP + FN))
    *   **Precision (정밀도) / Positive Predictive Value (PPV):** 모델이 Positive(이탈)로 예측한 것 중 실제 Positive(이탈)인 비율. **FP(False Positive)를 줄이는 것이 중요할 때** (이탈 예측으로 인한 불필요한 비용 발생을 막아야 할 때) 중요. (TP / (TP + FP))
    *   **F1-Score:** Precision과 Recall의 조화 평균. 두 지표가 모두 중요할 때 사용. (2 \* Precision \* Recall / (Precision + Recall))
    *   **AUC (Area Under the ROC Curve):** 모델이 Positive와 Negative를 얼마나 잘 구별하는지를 나타내는 지표. 특정 임계값(Threshold)에 의존하지 않고 모델의 전반적인 판별 성능을 평가.
    *   **Confusion Matrix (혼동 행렬):** TP, FP, FN, TN을 시각화하여 보여주는 표. 위 지표들을 계산하는 기본 요소.
3.  **불균형 데이터 처리 기법:**
    *   **데이터 레벨 접근 (Data-level Approach):**
        *   **언더샘플링 (Undersampling):** 다수 클래스 데이터 제거 (Random, Tomek Links, ENN 등). 데이터 손실 우려.
        *   **오버샘플링 (Oversampling):** 소수 클래스 데이터 증식 (Random, SMOTE, ADASYN 등). 과적합 또는 노이즈 증폭 우려.
    *   **알고리즘 레벨 접근 (Algorithm-level Approach):**
        *   **비용 민감 학습 (Cost-Sensitive Learning):** 소수 클래스 분류 오류(FN)에 더 높은 비용(가중치) 부여.
        *   불균형 데이터에 강건한 모델 사용 (예: Tree 기반 앙상블 모델 - RandomForest, XGBoost, LightGBM 등).
    *   **평가 및 임계값 조정 (Evaluation & Threshold Adjustment):**
        *   모델 예측 확률(Probability)의 분류 임계값 조정 (기본값 0.5 대신 Recall을 높이는 방향으로 조정). Precision-Recall Curve 참고.
4.  **Precision-Recall Trade-off:** Recall을 높이려 하면(예: 임계값 낮추기), 모델이 더 많은 샘플을 Positive로 예측하게 되어 FP가 증가하고 Precision이 낮아지는 경향. 반대도 마찬가지. 비즈니스 요구사항에 맞춰 적절한 균형점 또는 우선순위 결정 필요.

### 주의사항

후보자의 답변을 평가할 때 다음 사항에 유의해야 합니다.

1.  **Accuracy 함정 인지:** 후보자가 왜 Accuracy가 이 문제 상황에서 부적절한 지표인지 명확히 설명하는지 확인합니다. 단순히 "데이터가 불균형해서"를 넘어, 다수 클래스만 잘 맞춰도 Accuracy가 높아지는 메커니즘을 이해하고 설명하는지 봅니다.
2.  **지표의 맥락적 이해:** 단순히 Recall, Precision 등을 나열하는 것을 넘어, 각 지표가 *이 비즈니스 문제(이탈 예측)* 에서 어떤 의미를 가지는지, 왜 Recall이 특히 중요한지(FN의 비용) 설명하는지 확인합니다.
3.  **해결 방안의 구체성 및 실현 가능성:** "데이터를 늘린다", "모델을 튜닝한다" 와 같은 추상적인 답변 대신, 구체적인 기법(SMOTE, 비용 민감 학습, 임계값 조정 등)을 언급하고, 그 원리를 간략하게라도 설명하는지 확인합니다. 제시된 방법이 실제 적용 가능한 수준인지 평가합니다.
4.  **Trade-off에 대한 명확한 인식:** Recall 개선 방안 제시 시, 해당 방법이 Precision에 미칠 수 있는 영향(일반적으로 하락)과 그 이유를 명확히 설명하는지 확인합니다. 이 Trade-off를 어떻게 관리할 것인지(예: 비즈니스 목표에 따른 임계값 선택, F1-score 고려 등)에 대한 고민이 드러나는지 봅니다.
5.  **문제 원인 추론의 논리성:** 낮은 Recall의 원인을 추론할 때, 데이터(불균형, 피처 부족/품질), 모델(알고리즘 선택, 하이퍼파라미터), 학습 방식(손실 함수, 평가 지표 설정) 등 다양한 측면을 균형 있게 고려하며 논리적으로 접근하는지 확인합니다.

### 질문 가이드

면접관은 후보자의 이해도를 깊이 있게 파악하기 위해 다음과 같은 질문을 활용할 수 있습니다.

1.  **평가지표 관련 심층 질문:**
    *   "Accuracy 외에 다른 지표들이 왜 중요한지 설명해주셨는데, 이 문제 상황에서 *가장* 중요하게 봐야 할 지표는 무엇이라고 생각하시나요? 그 이유는 무엇인가요?" (비즈니스 임팩트와 연결 능력 확인)
    *   "Recall과 Precision의 관계는 보통 어떻게 나타나나요? Recall을 높이기 위한 조치가 비즈니스에 미칠 수 있는 다른 영향(부작용)은 무엇일까요?" (Trade-off 이해도 확인)
    *   "AUC 스코어는 어떤 장점이 있어서 불균형 데이터셋 평가에 자주 사용될까요?" (임계값 독립적 평가 이해도 확인)
    *   "(필요시) Recall, Precision, F1-score를 Confusion Matrix의 TP, FP, FN, TN을 이용해 설명해주실 수 있나요?" (기본 개념 숙지 확인)
2.  **원인 분석 관련 심층 질문:**
    *   "데이터 불균형 외에, 낮은 재현율의 또 다른 가능한 원인은 무엇이 있을까요? (예: 피처 엔지니어링, 모델 복잡도 등)" (다각적 사고 능력 확인)
    *   "사용한 모델이 구체적으로 어떤 종류였는지 알 수 있다면, 모델 자체가 원인이 될 수도 있을까요?" (모델 특성 이해도 확인)
3.  **해결 방안 관련 심층 질문:**
    *   "언급하신 해결 방안 중 (예: SMOTE)을 사용했을 때 발생할 수 있는 단점이나 주의할 점은 무엇일까요?" (기술의 장단점 이해도 확인)
    *   "분류 임계값(Threshold)을 조정한다고 하셨는데, 어떤 기준으로 '최적의' 임계값을 결정할 수 있을까요? 어떤 도표나 분석이 도움이 될까요?" (Precision-Recall Curve, 비즈니스 요구사항 기반 결정 등 실용적 접근 확인)
    *   "데이터 처리 기법(샘플링)과 모델링 기법 변경(비용 민감 학습) 중 어떤 방법을 먼저 시도해보시겠어요? 그 이유는 무엇인가요?" (문제 해결 전략 및 우선순위 설정 능력 확인)
    *   "만약 Recall을 개선하는 과정에서 Precision이 너무 낮아져 문제가 된다면, 그 다음에는 어떤 조치를 취해볼 수 있을까요?" (복합적인 문제 해결 능력 및 Trade-off 관리 능력 확인)
4.  **종합 및 커뮤니케이션 질문:**
    *   "이 문제를 해결하기 위해 내일부터 당장 어떤 순서로 작업을 진행하실 건가요?" (실행 계획 및 구조화 능력 확인)
    *   "개선된 모델의 성능(예: Recall은 높아졌지만 Precision은 낮아짐)을 비기술적인 이해관계자(예: 마케팅팀)에게 어떻게 설명하고 설득하시겠어요?" (결과 해석 및 커뮤니케이션 능력 확인)
