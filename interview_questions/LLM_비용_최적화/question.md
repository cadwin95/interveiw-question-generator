```markdown
### 문제 제목
LLM 비용 최적화

### 문제 설명
**상황:**
귀하는 현재 월간 활성 사용자(MAU) 10만 명 규모의 고객 지원 챗봇 서비스를 운영하는 팀의 AI 엔지니어입니다. 이 챗봇은 **주로 제품 정보 안내 및 비교적 간단한 FAQ 응대에 사용**되며, 외부 LLM API(예: GPT-4, Claude 3 Opus 등 고성능 모델)를 기반으로 작동합니다. 사용자 질문에 대한 답변 생성 비용이 서비스 전체 운영 비용의 상당 부분을 차지하고 있으며, 최근 사용자 증가와 함께 LLM API 호출 비용이 예산을 초과하기 시작했습니다. 챗봇의 **핵심 기능(정확한 정보 제공, 자연스러운 대화 흐름 유지)**을 크게 저해하지 않으면서, **LLM API 호출 비용을 현재 대비 최소 30% 절감**하는 것이 과제입니다. **답변 시 필요한 가정이 있다면 명시**해 주십시오 (예: 평균 대화 길이, 질문 복잡도 분포 등).

**요구사항:**
1.  비용 절감을 위한 최소 3가지 기술적 전략을 구체적으로 제시하십시오. (예: 프롬프트 최적화, 모델 변경/라우팅, 캐싱 전략, 응답 길이 제어, 배치 처리 등)
2.  각 전략이 어떻게 비용 절감에 기여하는지 기술적 원리를 설명하십시오.
3.  각 전략을 구현했을 때 예상되는 비용 절감 효과(정성적 또는 대략적 정량적)와 챗봇 성능/품질(예: 답변 정확도, 응답 속도, 사용자 만족도)에 미칠 수 있는 영향(긍정적/부정적)을 분석하십시오.
4.  제시한 전략들 중 **가장 먼저 시도해 볼 만한 핵심 전략 1~2가지를 선택하고, 그 이유를 간략히 설명**하십시오. (예: 예상 효과, 구현 난이도, 성능 영향 등을 고려)
5.  이러한 변경 사항을 적용한 후 **비용 절감 효과와 서비스 품질 변화를 추적하기 위해 어떤 핵심 지표(KPI)들을 주로 모니터링**할 것인지 언급하고 그 이유를 간략히 설명하십시오. (예: API 호출 당 비용, 총 API 비용, 사용자 만족도 점수, 문제 해결률 등)

### 평가 포인트
- LLM 비용 구조 및 최적화 기법 이해도
- 기술적 접근의 구체성 및 실현 가능성
- 비용-성능 트레이드오프 분석 능력
- 가정 설정 및 문제 정의 능력
- 아이디어 구조화 및 설명 능력
- 핵심 파악 및 **우선순위 결정 논리**
- **핵심 지표(KPI) 선정 타당성**

### 제약 조건
- 답변 시간: 30분
- 발표 방식: 구두 설명 또는 간략한 메모 활용
- 목표: LLM API 비용 최소 30% 절감 및 핵심 기능(품질) 저하 최소화
```
