# AI 면접 문제 생성기 (Interview Question Generator)

이 도구는 Google Gemini AI를 활용하여 다양한 직업군과 주제에 맞춘 고품질 면접 문제를 자동으로 생성합니다. 기존 주제를 기반으로 새로운 주제를 자동 생성하고, 여러 단계의 검증을 통해 실전에서 활용 가능한 면접 문제를 제공합니다.

## 주요 기능

- 8개 직업군에 맞춤화된 면접 문제 생성
- 기존 주제 기반 자동 주제 생성
- 9단계 검증 및 개선 프로세스
- 마크다운 형식의 결과 저장
- 면접관을 위한 가이드라인 자동 생성
- 문제 해결을 위한 환경 설정 및 샘플 코드 생성

## 설치 방법

1. 필요한 패키지 설치:
```bash
pip install google-generativeai argparse python-dotenv
```

2. 환경 변수 설정:
   - `.env` 파일에 `GOOGLE_API_KEY=your_api_key` 추가

## 사용 방법

### 기본 사용법
```bash
python main.py
```

### 사용 가능한 매개변수

| 매개변수 | 설명 |
|---------|------|
| `--test-type` | 문제 생성 모드 (`creative`, `complex`, `default`) |
| `--no-save` | 결과 파일 저장 안 함 |
| `--topic` | 특정 주제 지정 (지정하지 않으면 자동 생성) |
| `--job` | 직업군 지정 (기본값: ai_engineer) |
| `--time-limit` | 문제 해결 제한 시간(분) (기본값: 30분) |

### 예시

1. 자동 주제 생성 및 문제 생성:
```bash
python main.py --job ai_engineer --time-limit 120
```

2. 특정 주제로 문제 생성:
```bash
python main.py --job ai_engineer --topic "금융 데이터 품질 관리" --time-limit 120
```

## 생성 프로세스

1. **주제 생성**: 기존 주제를 기반으로 새로운 주제 자동 생성
2. **초기 문제 기획**: 선택된 주제와 직업군에 맞는 기본 면접 문제 생성
3. **논리 검증**: 문제의 논리적 일관성과 명확성 검토
4. **난이도 조정**: 적절한 난이도로 문제 수준 조정
5. **창의성 강화**: 문제에 창의적 요소 추가
6. **복잡성 증가**: 난해한 요소 추가로 심층적 사고 유도
7. **단순화**: 불필요한 복잡성 제거 및 문제 정교화
8. **최종 검토**: 문제의 품질과 평가 기준 확정
9. **데이터 생성 코드**: 문제 해결에 필요한 환경 및 데이터 생성 코드 제공
10. **면접관 가이드**: 면접관이 참고할 수 있는 주요 개념 및 평가 포인트 제공

## 출력 결과

생성된 결과는 `interview_questions` 디렉토리에 저장됩니다:
- `question.md`: 문제 설명 및 요구사항
- `interviewer_guide.md`: 면접관 가이드
- `generate_data.py`: 데이터 생성 코드
