### 문제 제목
AI 문구 품질 검증

### 문제 설명

**AI 생성 마케팅 문구 자동 품질 검증 시스템 설계**

**상황:**

당신은 AI 기반 마케팅 문구 생성 서비스를 개발하는 팀의 AI 엔지니어입니다. 이 서비스는 **상품 정보, 타겟 고객 특성, 요청 톤앤매너** 등을 입력받아 마케팅 문구를 자동으로 생성합니다. 최근 서비스가 생성하는 문구의 품질이 일관되지 않다는 사용자 피드백이 증가했습니다. 특히, 다음과 같은 문제가 발생합니다:

*   **브랜드 가이드라인 위반:** 긍정적 어조 유지 실패, 특정 금지어 사용, 최대 글자 수 초과 등
*   **입력 문맥과의 불일치:** 생성된 문구가 입력된 상품의 특징이나 타겟 고객과 동떨어진 내용을 포함하는 경우

**과제:**

이 문제를 해결하기 위해, AI 모델이 **새로 생성한 마케팅 문구의 품질과 일관성을 자동으로 검증하는 시스템**을 설계하고 설명해야 합니다. **준비 시간은 30분**이며, 이후 구두 발표 및 질의응답이 진행됩니다.

**요구사항:**

1.  **핵심 검증 지표 정의:** 최소 3가지 이상의 구체적인 자동 검증 지표를 정의하고, 각 지표가 **주어진 문제점(브랜드 가이드라인 위반, 입력 문맥 불일치) 해결**에 어떻게 직접적으로 기여하는지 설명하세요.
    *   (예시: 긍정/부정 감성 점수, 금지어 포함 여부, 글자 수, 입력된 상품 특징 키워드 포함 여부, 타겟 고객 관련성 점수 등)
2.  **검증 프로세스 설계:** 새로운 문구가 생성되었을 때, 정의된 지표들을 사용하여 자동으로 품질을 검증하는 전체 워크플로우를 단계별로 설명하세요. 코드 레벨 구현보다는 **주요 로직, 데이터 흐름, 자동화된 판단 기준** 중심으로 설명해야 합니다.
3.  **기술적 고려사항 및 해결 방안:** 설계한 검증 프로세스를 실제로 구현할 때 예상되는 **가장 중요한 기술적 어려움 1~2가지**를 선정하고, 이에 대한 **구체적인 해결 또는 완화 방안**을 제시하세요.
    *   (예: 특정 지표 측정의 정확도 한계 및 개선 방안, 실시간 처리 요구사항 충족 방안, 다양한 문맥 변화에 대한 시스템의 강건성 확보 방안 등)
    *   (참고: 시스템의 장기적인 발전 방향에 대한 아이디어는 준비 시간에 필수는 아니며, 발표나 질의응답 시 추가적으로 논의될 수 있습니다.)

**평가 기준:**

*   문제 상황 및 요구사항 이해도
*   정의된 검증 지표의 구체성, 적절성, 측정 가능성 및 문제 해결 기여도
*   검증 프로세스 설계의 논리성, 실현 가능성 및 효율성
*   기술적 문제 예측 및 해결/완화 방안의 타당성 및 구체성
*   AI 결과물 품질 관리에 대한 깊이 있는 사고
*   설명의 명확성 및 구조화

**발표:**

*   주어진 **준비 시간(30분)** 내에 답변을 구상합니다. (간단한 다이어그램이나 키워드 메모 가능)
*   준비 시간이 끝나면 구두로 **설계 내용을 설명**합니다. (약 10-15분 예상)
*   설명 후 질의응답 시간이 주어집니다.

1. 자동 실행 스크립트 사용:
```bash
./run_data_generation_20250414_143137.sh
```

2. Python 스크립트 직접 실행:
```bash
python generate_data.py
```
