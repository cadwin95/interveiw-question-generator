### 문제 제목
**실시간 사용자 감정 반응형 뉴스 추천 시스템 프로토타입 개발**

### 문제 설명
사용자가 뉴스 기사를 읽고 표현하는 감정(긍정, 부정, 중립)에 실시간으로 반응하여, 다음에 추천될 뉴스 목록을 개인화하고 동적으로 조절하는 시스템의 핵심 로직 프로토타입을 Python으로 개발합니다. 이 과제는 AI 모델(감정 분석)의 결과를 활용하여 실제 서비스 로직을 설계하고 구현하는 능력을 평가합니다.

**과제:**

1.  **샘플 데이터 생성:** 아래 구조를 따르는 가상의 샘플 데이터를 Python 코드로 생성합니다. (뉴스 기사 5~10개 규모)
    *   **뉴스 기사 데이터 (`articles` - 리스트 또는 딕셔너리 형태):**
        *   `article_id` (문자열, 고유 식별자, 예: "news001")
        *   `title` (문자열, 기사 제목)
        *   `category` (문자열, 기사 카테고리, 예: "정치", "경제", "사회", "IT/과학", "생활/문화", "스포츠")
        *   `predefined_sentiment` (정수형, 기사 자체의 일반적인 톤앤매너 추정치, 예: 1(긍정적), 0(중립적), -1(부정적)). 추천 로직 설계 시 **선택적으로 활용 가능한** 정보입니다.

2.  **감정 분석 결과 활용 가정:** 시스템은 사용자가 특정 기사(`article_id`)를 읽고 감정(`emotion` - "positive", "negative", "neutral")을 표현하면, 이 최신 정보를 즉시 알 수 있다고 가정합니다. 별도의 감정 분석 모델 구현은 필요하지 않습니다.

3.  **핵심 추천 로직 함수 구현:**
    *   사용자의 가장 최근 반응(`last_article_id`, `last_emotion`)과 전체 뉴스 기사 목록(`all_articles`)을 입력받아, 해당 사용자에게 다음에 보여줄 뉴스 기사 목록(예: 상위 3개)을 추천하는 `recommend_next_articles(last_article_id: str, last_emotion: str, all_articles: list)` 함수를 구현합니다.
    *   **핵심 요구사항 (자신만의 합리적인 규칙 설계 및 근거 설명):**
        *   **긍정적 감정 ("positive"):** 사용자가 긍정적 감정을 보인 기사(`last_article_id`)와 **동일한 카테고리**의 다른 기사들의 추천 우선순위를 높입니다. (예: 해당 카테고리 기사에 가산점 부여)
        *   **부정적 감정 ("negative"):** 사용자가 부정적 감정을 보인 기사와 **동일 카테고리**의 기사 추천 우선순위를 낮추거나 제외합니다. (예: 감점 또는 필터링). 대신, **다른 카테고리** 중 `predefined_sentiment`가 긍정적이거나 중립적인 기사를 우선적으로 보여주어 분위기 전환을 유도할 수 있습니다.
        *   **중립적 감정 ("neutral"):** 특정 카테고리에 치우치지 않도록 다양한 카테고리의 기사를 보여주거나, (가상의) `popularity_score` 등을 가정하여 인기 기사를 추천할 수 있습니다. 또는 단순히 읽지 않은 다른 기사를 랜덤하게 섞어 보여줄 수도 있습니다. **어떤 방식을 선택했는지, 왜 그 방식을 선택했는지 명확히 설명해야 합니다.** (주석 또는 별도 설명)
        *   **중복 제외:** 이미 읽은 기사(`last_article_id`)는 추천 목록에서 제외해야 합니다.
    *   **구현 방식:** 점수 기반 시스템(각 기사에 점수를 매겨 정렬) 또는 명확한 규칙 기반 필터링/선택 시스템으로 구현합니다.

4.  **결과 시연:** 생성한 샘플 데이터와 가상의 사용자 최근 감정 입력(예: 'news001' 기사에 'positive' 반응)을 이용하여, `recommend_next_articles` 함수의 결과(추천 기사 ID 목록)가 사용자의 마지막 감정에 따라 어떻게 달라지는지 보여주는 간단한 시뮬레이션 코드를 작성하고 실행 결과를 출력합니다.

### 채점 가이드

*   **로직 설계:** 정해진 정답은 없습니다. 지원자가 제시한 규칙/점수 시스템이 '왜' 합리적인지 설명하는 논리성을 중점적으로 평가합니다. 예를 들어, 부정적 감정 시 해당 카테고리를 완전히 제외하는 방식과 점수를 크게 감점하는 방식 중 어떤 것을 선택했고 그 이유는 무엇인지 등을 봅니다. 창의적인 아이디어(예: 중립 감정 시 참신한 처리 방식)는 가산점을 받을 수 있습니다.
*   **코드 품질:** 단순히 동작하는 코드를 넘어, 다른 사람이 이해하기 쉽도록 작성되었는지(변수명, 함수 구조, 주석 등) 평가합니다. 복잡한 로직 없이도 표준 라이브러리만으로 깔끔하게 구현하는 능력을 봅니다. Pandas 사용 시, 핵심 로직 구현에 집중했는지 확인합니다. (Pandas 기능 남용으로 핵심 로직이 가려지면 감점될 수 있음)
*   **결과 시연:** 시뮬레이션 코드가 다양한 감정 입력에 따라 추천 결과가 어떻게 달라지는지 명확히 보여주는지 확인합니다. 결과 출력 형식이 깔끔하고 이해하기 쉬운지 평가합니다.
*   **시간 관리:** 제한 시간 내 완성도를 평가하되, 시간이 부족하여 일부 미흡하더라도 핵심 로직 설계 및 구현 능력이 잘 드러난다면 긍정적으로 평가합니다.
*   **(면접 시 논의 가능)** 코드 리뷰 중, 감정 기반 추천이 가질 수 있는 잠재적 문제점(예: 감정 편향 심화, 필터 버블)에 대해 질문하여 시스템적 사고 능력을 추가로 확인할 수 있습니다. (코드 구현 요구사항 아님)

### 참고사항

*   이 문제는 AI 모델 자체를 개발하는 것이 아니라, **AI 모델의 출력(감정 분석 결과)을 활용하여 서비스 로직을 만드는 능력**을 평가하는 데 중점을 둡니다.
*   외부 라이브러리 사용은 최소화하고 Python 기본 문법과 자료구조를 활용하여 핵심 로직 구현에 집중해주세요. `pandas`는 선택적으로 사용 가능하나 필수는 아닙니다.
*   함수(`recommend_next_articles`)의 입력과 출력 형식을 명확히 정의하고 구현해주세요.
*   코드 내에 주석을 적극적으로 활용하여 로직 설계 의도를 설명하면 평가에 도움이 됩니다.
*   시간 제약(1시간 30분 ~ 2시간 권장)이 있으므로, 완벽함보다는 핵심 요구사항을 충족하는 프로토타입 완성에 집중해주세요.
