### 문제 제목
챗봇 일관성 모니터링

### 문제 설명
**상황:**
당신은 고객 문의에 답변하는 AI 챗봇 서비스를 운영하는 팀의 AI 엔지니어입니다. 최근 챗봇 모델 업데이트 후, 일부 사용자들이 "같은 질문에도 챗봇의 답변 스타일이나 정보의 상세 수준이 이전과 다르게 변동성이 커졌다"는 피드백을 주기 시작했습니다. 전반적인 답변의 정확도는 유지되고 있지만, 답변의 일관성이 떨어지는 문제가 발생하고 있습니다.

**요구사항:**
1. 챗봇의 답변 일관성을 모니터링하고 평가하는 시스템을 설계하고 구현하세요.
2. 동일한 질문에 대한 답변의 변동성을 측정할 수 있는 지표를 개발하세요.
3. 답변의 스타일과 정보의 상세 수준을 정량적으로 평가하는 방법을 제시하세요.
4. 일관성이 떨어지는 답변을 자동으로 감지하고 개선할 수 있는 방안을 제시하세요.

### 평가 포인트
- 답변 일관성 측정 지표의 적절성
- 모니터링 시스템의 실용성과 확장성
- 문제 해결 접근 방식의 창의성
- 코드 구현의 완성도와 효율성
- 에러 처리와 예외 상황 관리

### 제약 조건
- Python을 사용하여 구현해야 합니다.
- 외부 라이브러리는 최소한으로 사용해야 합니다.
- 실시간 모니터링이 가능해야 합니다.
- 시스템 리소스 사용을 최적화해야 합니다.
- 2시간 이내에 구현을 완료해야 합니다.

## 데이터 생성

데이터 생성 코드는 `generate_data.py` 파일에 저장되어 있습니다.

### 실행 방법
다음 방법 중 하나를 선택하여 실행할 수 있습니다:

1. 자동 실행 스크립트 사용:
```bash
./run_data_generation_20250414_144041.sh
```

2. Python 스크립트 직접 실행:
```bash
python generate_data.py
```

### 로그 확인
실행 로그는 `logs/data_generation.log` 파일에서 확인할 수 있습니다.
